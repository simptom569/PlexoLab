# Скриншоты эталона

Снимки сделаны с макета `design/Main.dc.html` в Chromium, окно 1440×900, шрифты Manrope и JetBrains Mono подключены локально. Два снимка на экран: светлая и тёмная тема.

Имена файлов: `<номер>-<экран>-<light|dark>.png`.

| № | Экран | Что на снимке |
|---|---|---|
| 01 | board | Доска, вид «Доска» |
| 02 | board-list | Вид «Список» |
| 03 | board-table | Вид «Таблица» |
| 04 | board-calendar | Вид «Календарь» |
| 05 | board-gantt | Вид «Ганта» |
| 06 | board-filters | Открыт поповер «Фильтры» |
| 07 | board-display | Открыт поповер «Отображение» |
| 08 | task-drawer | Правая панель задачи WEB-144 |
| 09 | backlog | Бэклог |
| 10 | modules | Модули |
| 11 | releases | Релизы и вехи |
| 12 | wiki-page | Вики, страница «Соглашения по коду» |
| 13 | wiki-edit | Вики, активный блок (виден исходник markdown) |
| 14 | wiki-files | Вики, «Файлы» |
| 15 | docs-list | Документы, список |
| 16 | doc-page | Документ «Планирование Q4», режим «Страница» |
| 17 | doc-canvas | Документ «Схема сервисов», режим «Холст» |
| 18 | activity | Активность |
| 19 | links | Ссылки команды |
| 20 | drag-card | Перенос карточки: заглушка (drop placeholder) в колонке «На ревью», источник приглушён |
| 21 | drag-column | Перенос колонки «Готово»: заглушка колонки (сама колонка справа за краем экрана, список прокручивается) |
| 22 | drag-backlog | Перенос строки бэклога: заглушка во всю ширину строки |
| 23 | drag-calendar | Перенос плашки в календаре: пунктирная плашка в ячейке-цели |

Что нужно знать:
- Состояние «активный блок» (13) и «перенос» (20–23) сняты в момент действия, указатель находится над целью.
- Корневой контейнер макета имеет `min-height:1380px`, в приложении он заменяется на `100vh` (см. `docs/COMPONENTS.md`). Снимки по высоте обрезаны окном 900 пикселей.
- В полях дат стоит системный формат браузера (`10/12/2026`). В приложении поле даты берёт формат ОС, это нормально.
- Если макет изменили, снимки нужно переснять.
