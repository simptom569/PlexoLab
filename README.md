# Пакет для Claude Code: PlexoLab

Здесь всё, что нужно, чтобы Claude Code собрал приложение **PlexoLab** по макету.

## Состав

```
CLAUDE.md                     правила проекта (положить в корень репозитория)
design/
  Main.dc.html                эталон: разметка, стили, логика (только чтение)
  styles.css                  весь CSS макета без изменений
  reference/markdown-engine.js  разбор markdown из макета, портировать в TS
  screenshots/                скриншоты эталона 01–23 в двух темах и список экранов
docs/
  ARCHITECTURE.md             стек, структура репозитория, развёртывание на сервере 1 ГБ
  SPEC.md                     что делает каждый экран
  COMPONENTS.md               где в макете какой блок и какие классы
  DATA-MODEL.md               таблицы Postgres, REST и WebSocket
  EDITOR-AND-CANVAS.md        поведение редактора markdown и холста
  PLAN.md                     этапы работы и готовые промпты
```

## Как начать

1. Создай пустой репозиторий и скопируй в него содержимое этого архива.
2. Скриншоты эталона уже лежат в `design/screenshots/` (23 экрана × светлая и тёмная тема, 1440×900). Если что-то в макете поменяешь, их нужно переснять, см. `design/screenshots/README.md`.
3. Открой репозиторий в Claude Code и вставь промпт этапа 0 из `docs/PLAN.md`.
4. Дальше иди по этапам. После каждого проверяй результат глазами и сравнивай с макетом.

## Иконка

В макете под иконку оставлено место в левом верхнем углу бокового меню (пунктирная заглушка 32×32). Путь к файлу иконки впиши в `CLAUDE.md`, в раздел «Бренд», в строку `ICON_PATH`. Пока он пустой, Claude Code оставит заглушку и не будет рисовать логотип сам. Когда впишешь путь, попроси подключить иконку: он поставит её в меню и сгенерирует иконки для установщика.

## Что нужно знать заранее

- Макет в формате `.dc.html` открывается только внутри Claude. Claude Code читает его как текст. Поэтому по скриншотам он видит, как должно выглядеть на самом деле. Они сняты в Chromium с локальными шрифтами Manrope и JetBrains Mono, так же, как будет рендерить WebView2.
- Скриншоты сравниваются в Chromium. На Windows Tauri использует WebView2 (тот же движок), поэтому внешний вид совпадёт. На macOS и Linux Tauri рисует через WebKit, возможны мелкие отличия. Это стоит проверить, если планируете эти системы.
- Текст интерфейса в макете русский. Меняется только если вы решите иначе.
