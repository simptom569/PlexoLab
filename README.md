# PlexoLab

Десктоп-приложение для небольшой команды разработки: канбан-доска, бэклог, модули, релизы и вехи, вики с файлами, документы (страница и холст), активность, ссылки команды. Клиент на Tauri 2 + React, бэкенд на Rust (axum) и PostgreSQL. Интерфейс повторяет макет из `design/`.

Правила проекта: `CLAUDE.md`. Этапы работы: `docs/PLAN.md`. Сейчас готов этап 0 (каркас).

## Состав

```
CLAUDE.md                     правила проекта
design/                       эталон интерфейса, только чтение
  Main.dc.html                макет: разметка, стили, логика
  styles.css                  весь CSS макета без изменений
  icon.png                    иконка приложения (440×440, временная)
  reference/markdown-engine.js  разбор markdown из макета, портируется в TS
  screenshots/                скриншоты эталона 01–23 в двух темах
docs/                         архитектура, спецификация, модель данных, план
server/                       бэкенд (cargo workspace)
  src/main.rs                 бинарник `server`
  src/bin/seed.rs             демо-данные (заглушка до этапа 2)
  crates/api|domain|db        роуты и middleware / бизнес-правила / доступ к БД
  migrations/                 миграции sqlx (с этапа 2)
app/                          клиент: Vite + React + TypeScript
  src-tauri/                  оболочка Tauri 2
tests/visual/                 Playwright: сравнение со скриншотами (с этапа 1)
deploy/                       systemd, Caddyfile, postgresql.conf, бэкапы (этап 10)
```

## Требования

- Rust stable (MSVC-тулчейн на Windows) и Visual Studio Build Tools с компонентом C++.
- Node.js 24 и npm.
- WebView2 (в Windows 11 уже есть).
- PostgreSQL нужен с этапа 2 для бэкенда и его тестов. Для этапа 0 не нужен.

## Команды

Запускать из корня репозитория:

| Команда | Что делает |
|---|---|
| `npm run dev-server` | запускает сервер, по умолчанию на `127.0.0.1:8080` (переменные `BIND_ADDR`, `RUST_LOG`) |
| `npm run dev-app` | запускает клиент в окне Tauri (первая сборка занимает несколько минут) |
| `npm run dev-app-web` | клиент в обычном браузере на `http://localhost:1420`, без Tauri |
| `npm run test` | тесты сервера и проверка типов и сборки клиента |
| `npm run build-server` | релизная сборка сервера |
| `npm run build-app` | установщик NSIS (настройки упаковки появятся на этапе 9) |

Проверка сервера: `GET http://127.0.0.1:8080/healthz` отвечает `ok`.

Перед первым запуском клиента: `npm --prefix app install`.

## Идентификатор и иконка

- **Идентификатор приложения:** `com.simptom.plexolab` (`app/src-tauri/tauri.conf.json`). После выпуска его менять нельзя: Windows посчитает приложение другим, настройки и вход пропадут.
- **Иконка (временная, можно заменить).** Сейчас используется `design/icon.png` (440×440), её копия лежит в `app/src/assets/icon.png`. Для хорошего качества `.icns` и крупных размеров нужна PNG 1024×1024 с прозрачным фоном. Чтобы заменить: положить новый файл на место `design/icon.png`, скопировать его в `app/src/assets/icon.png` и выполнить `npm --prefix app run tauri icon src/assets/icon.png`. Каталоги `icons/android` и `icons/ios` после этого удалить, мобильные сборки не нужны.

## Что нужно знать заранее

- Макет в формате `.dc.html` открывается только внутри Claude. Claude Code читает его как текст. По скриншотам видно, как должно выглядеть на самом деле. Они сняты в Chromium с локальными шрифтами Manrope и JetBrains Mono, так же, как будет рендерить WebView2.
- Скриншоты сравниваются в Chromium. На Windows Tauri использует WebView2 (тот же движок), поэтому внешний вид совпадёт. На macOS и Linux Tauri рисует через WebKit, возможны мелкие отличия.
- Текст интерфейса в макете русский. Меняется только если вы решите иначе.
