# Документация PlexoLab

Короткое знакомство с проектом, быстрый старт и скриншоты: [корневой README](../README.md). Здесь технические документы, сгруппированные по тому, зачем их открывают.

## Начать здесь

| Документ | О чём |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | как устроена система: клиент, сервер, база, структура репозитория, развёртывание на сервере с 1 ядром и 1 ГБ памяти |
| [SPEC.md](SPEC.md) | поведение каждого экрана: что делает каждый элемент и по каким правилам |
| [ROADMAP.md](ROADMAP.md) | дорожная карта: этапы, критерии готовности, что сделано и что впереди |
| [DEVELOPMENT.md](DEVELOPMENT.md) | запуск и эксплуатация: настройки сервера, пользователи, демо-данные; устройство клиента по экранам; тесты; сборка и релиз в GitHub Actions |
| [DEPLOY.md](DEPLOY.md) | как поставить сервер на свой Linux: база, служба systemd, первый пользователь, HTTPS, резервные копии, обновление и откат |

## Возможности

Каждая крупная возможность описана отдельно: как работает для человека, какие решения приняты и почему.

| Документ | О чём |
|---|---|
| [TEAMS.md](TEAMS.md) | команды, личная команда «Личное», видимость проектов, вики и файлы по командам |
| [PROJECTS.md](PROJECTS.md) | проекты, участники, приглашения, права, ключи задач (`WEB-144`) |
| [EDITOR-AND-CANVAS.md](EDITOR-AND-CANVAS.md) | markdown-редактор в стиле Obsidian и холст документов |
| [OFFLINE-NOTIFY-SEARCH.md](OFFLINE-NOTIFY-SEARCH.md) | работа без связи, уведомления и `@упоминания`, трей и автозапуск, поиск |
| [REGISTRATION.md](REGISTRATION.md) | регистрация и сброс пароля по коду из письма (Resend) |

Если `PROJECTS.md` и `TEAMS.md` расходятся, прав `TEAMS.md`: он новее.

## Эталон интерфейса

Лежит вне `docs/`, только для чтения: [`design/`](../design/). Макет `Main.dc.html`, весь CSS `styles.css` и [скриншоты экранов](../design/screenshots/README.md) в двух темах. Приложение сверяется с ними автоматически (`npm run test-visual`).

Картинки для корневого README лежат в [`screenshots/`](screenshots/), переснимаются командой `npm run readme-media`.
