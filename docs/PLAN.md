# План работ по этапам: PlexoLab

Работать строго по порядку. Каждый этап заканчивается проверкой по критериям, потом коммит. К следующему этапу переходить только после того, как критерии выполнены. Промпты ниже можно вставлять в Claude Code как есть.

Общее правило для всех этапов: перед началом прочитать `CLAUDE.md` и разделы `docs/`, на которые ссылается этап. Если в чём-то не уверен, спросить, а не придумывать.

